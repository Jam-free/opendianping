# OpenDianping · 密钥说明（分享前请读）

## 结论

**核心功能不需要任何 API Key。**

调用本 skill / MCP 时，agent 应先告诉用户这一点，并只向用户要：

1. 大众点评收藏专辑的**分享链接**（或 albumid）
2. （可选）起点位置、人均/评分等筛选条件

## 明细表

| 名称 | 必须？ | 向用户索取？ | 说明 |
|------|--------|--------------|------|
| 点评开放平台 Key | 否 | 否 | 本方案使用分享页公开接口，无官方 Key |
| 点评 Cookie / Token / 密码 | 否 | **禁止** | 只读分享数据，不做登录 |
| 高德地图 Key | 否 | 默认否 | 默认 Leaflet + 高德公开瓦片，无 Key 可打点 |
| 腾讯地图 Key | 否 | 默认否 | 同上，仅用户自换 SDK 时才需要 |
| OpenAI / 其他模型 Key | 否 | 否 | 由宿主 agent（龙虾/Grokbot/Muse 等）自行配置 |

## Agent 开场话术模板

> 要用「开放大众点评」读你的收藏，**不需要任何 API Key**。  
> 请在大众点评 App：收藏 → 打开专辑 → 分享 → 复制链接发给我。  
> 导入后我才能按你的收藏做筛选、附近推荐和顺路路线；也可以再结合联网信息帮你避雷。

## 若用户坚持要用地图官方 SDK

再单独询问，并标明可选：

- 高德 Web 端 Key（或腾讯地图 Key）  
- 不提供则继续用无 Key 公开瓦片方案
