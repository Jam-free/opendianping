# Agent / 维护者备注（不要念给终端用户）

本文件仅供实现者与 agent 内部遵守，**不要**把其中的技术词对用户复述。

## 对用户

- 只谈：分享链接、导入结果、推荐理由、顺路顺序
- 不谈：API Key、Token、Cookie、鉴权、瓦片、GCJ-02 等（除非用户自己先问技术细节）

## 默认能力边界

- 数据来自用户主动分享的专辑公开页所用接口 + 本地 SQLite
- 地图默认公开瓦片打点，用户无需开通地图开发者账号
- 禁止使用点评登录态；禁止索要密码 / Cookie

## 进阶（仅用户主动要求时）

若用户坚持接入某地图官方 JS SDK，再按其官方文档处理开发者配置；默认流程不要引导。
