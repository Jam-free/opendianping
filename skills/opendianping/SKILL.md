# OpenDianping Skill（开放大众点评）

把用户**主动分享**的点评收藏专辑变成可查询数据，再结合联网信息做推荐。

## 0. 对用户怎么说（产品语言）

对用户**只**说明：

> 把大众点评里收藏专辑的「分享链接」发给我。  
> 路径：收藏 → 打开专辑 → 分享 → 复制链接。  
> 导入后我就能按你的收藏做筛选、附近推荐和顺路路线，也可以再结合网上的近期评价帮你避雷。

**不要**对用户提：API Key、Token、Cookie、开发者密钥、鉴权等技术说法。  
用户需要提供的只有：**分享链接**（以及可选的位置、人均、品类等偏好）。

## 1. Agent 内部前置检查（勿原样念给用户）

按顺序：

1. MCP 工具是否可用：`import_album` / `list_shops` / `get_shop` / `shops_near` / `plan_route`
2. 若不可用 → 用下方「安装与连接」引导用户装好，**停下等待**，不要编造店铺数据
3. 若可用 → 向用户要专辑分享链接（尚未导入则先 `import_album`）

**禁止向用户索要或使用：**

- 点评账号密码、验证码、登录态、Cookie
- App 签名、批量爬取手段
- 任何「帮我登录你的点评」类操作

默认链路用公开分享数据 + 本地存储即可完成；地图默认也无需用户额外开通地图开发者账号。仅当用户**主动要求**换成某地图官方 SDK 时，再按其官方文档单独处理（那是进阶选项，不是默认流程）。

## 2. 用户侧需要提供什么

| 用户提供 | 必须？ | 示例（对用户可说） |
|----------|--------|-------------------|
| 收藏专辑分享链接 | ✅ 首次导入必须 | 点评 App 里专辑的分享链接 |
| 起点 / 区域（附近或路线时） | 场景需要时 | 「五一广场附近」 |
| 筛选条件 | 可选 | 人均、评分、品类 |

说明：只能读**分享出来的专辑**，不能自动同步整个点评账号。想导入多个专辑，就多贴几次链接。

## 3. 工具怎么用（MCP）

### `import_album`
- 输入：`url`（分享链接）；可选 `use_fixtures=true`（仅演示）
- 何时用：用户新贴链接，或本地还没有该专辑
- 会自动翻页拿全整个专辑（50+ 家也能完整导入）；专辑没有标题时以「专辑{albumid}」命名

### `list_shops`
- 输入：可选 `album_id`、`min_price`、`max_price`、`min_score`、`category`
- 何时用：按条件筛「我的收藏」

### `get_shop`
- 输入：`shop_id`
- 何时用：单店详情、招牌菜、推荐理由
- 返回含 `headImg`、`fiveScore`、`reviewNumber`、`webUrl`（用于卡片展示）

### `shops_near`
- 输入：`lat`、`lng`、可选 `radius_km`（默认 5）
- 坐标按国内常用地图坐标系理解（与点评一致）
- 何时用：「附近有哪些我收藏过的」

### `plan_route`
- 输入：`shop_ids` + `start_lat` + `start_lng`
- 何时用：顺路探店顺序（就近排序，不是导航路况）

## 4. 推荐流程

1. **开场**：用第 0 节产品话术，只要分享链接。  
2. **导入**：调用 `import_album`。失败用白话说明（链接无效、暂时连不上），演示样例勿当成用户真实收藏。  
3. **收藏优先 + 联网融合**：  
   - 先理解需求：地点/片区、口味、人均、人数、场合。  
   - 先从收藏里挑符合需求的店作为主力候选。  
   - 以下情况联网补 1–3 家收藏外的店：收藏里合适的不够；需求片区收藏没覆盖；想要的菜系收藏里没有。用户说「只要我收藏的」就不补；说「多推点新的」就多补。  
   - 收藏外的店只写查得到的真实信息（店名、评分、人均、出处），不编 shopId、不爬点评、不登录。  
   - 可联网给所有候选验鲜：近期评价、排队、是否还在营业，标注实时信息可能变化。  
4. **按「输出格式」呈现**（见下一节）。

## 5. 输出格式

每家店一张卡片：

- **店名**：用文字直接写出  
- **店铺头图**：收藏店用 `headImg`，作为图片展示而非只贴链接；收藏外的店有公开图片才配，不用无关图片冒充  
- **评分**：`fiveScore`、评价数、人均、片区  
- **一句推荐理由**：招牌菜 / 适合谁；不强制标注来源，需要时在推荐理由里自然带一句即可（如「你之前收藏过」）  

最后给出顺路顺序或分组建议，并说明哪些信息未核实。

## 6. 硬性约束

- 只读；不登录点评；不写入收藏；不伪造签名；不批量爬取
- 不索要、不存储用户点评登录态
- 完整地址 / 电话通常不可得——如实说明
- 没有导入成功前，禁止声称「已读取你的收藏」

## 7. 安装与连接

本 skill 依赖同仓库的 MCP 服务。需要本机已安装 Node.js 22+（better-sqlite3 要求），以及编译工具（如 build-essential / Xcode CLT）。

```bash
cd <opendianping项目目录>
npm install
npm run mcp
```

### Claude Desktop

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "opendianping": {
      "command": "npm",
      "args": ["run", "mcp"],
      "cwd": "/绝对路径/到/opendianping"
    }
  }
}
```

重启后应出现：`import_album`、`list_shops`、`get_shop`、`shops_near`、`plan_route`。

### Cursor / 其他支持 MCP 的 Agent

添加同等 MCP 配置：`command=npm`，`args=["run","mcp"]`，`cwd=项目绝对路径`。

### 可选 Web 界面

```bash
npm run dev
```

浏览器打开本地地址，可可视化导入与导出；与 MCP 共用本地数据。

## 8. 故障排查（对用户用白话）

| 情况 | 怎么说 / 怎么做 |
|------|-----------------|
| 工具连不上 | 请对方按安装说明装好项目并重启 AI 客户端 |
| 导入失败 | 请确认是专辑「分享链接」；可换一个专辑再试 |
| 想「同步全部收藏」 | 说明目前做不到，引导按专辑分享、多次导入 |
