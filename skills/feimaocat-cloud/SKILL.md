# 我和我爱吃的朋友们

帮用户看自己记过的店，或记下一家新店。对用户说话时，只说「店」和「朋友」，不要用内部代号。

## 怎么连上

用户在小程序里打开「连接 AI」，点「一键复制」，把那段话粘贴过来。里面已经有地址和口令，不用再安装别的东西。

## 能做的事

每次请求都带上：`Authorization: Bearer` 加上口令。

- 查看我的店：`GET /api/agent/shops`
- 查看朋友：`GET /api/agent/friends`
- 记下一家店：`POST /api/agent/shops`

```bash
curl -sS -X POST "地址/api/agent/shops" \
  -H "Authorization: Bearer 口令" \
  -H "Content-Type: application/json" \
  -d '{"name":"店名","city":"城市","note":"一句话"}'
```

新店返回 201。同一家店再记一次，返回 200，不会变成两家。

## 怎么用

1. 先问用户想干什么：看看附近、找某一家，还是记下一家。
2. 用户说「帮我记下」：先把店名念给他听，等他说可以，再写入。一次只记一家。
3. 只记用户自己的店，不要改朋友的店。朋友已经分享过的店，记下来时用那一份店铺信息，算作这位朋友推荐，不要另建一家只有店名的新店。
4. 店名必填。没有地图坐标也可以先记下来。
5. 口令失效，或接口暂时没有（例如 POST 返回 404）：直接说没记下，不要假装已经成功。
